# AI 竞品分析系统

一个本地优先的 HTML 工具：只输入目标产品名称，也可以自动联网发现竞品、核对公开来源，并按需求、行业、产品五层、AI 专项、数据系统、商业效率和决策建议完成分析。结果可导出为项目 JSON、带逐页演讲备注的 PPTX 与完整 Word 报告。

## 启动

在 PowerShell 中运行：

```powershell
.\scripts\start.ps1
```

脚本会查找 Codex Desktop 自带的 Node.js 与 Office 生成运行库，启动后打开 `http://127.0.0.1:4173`。DeepSeek 密钥可以通过两种方式提供：

1. 启动前设置 `DEEPSEEK_API_KEY` 环境变量。
2. 在网页的“模型设置”中输入；密钥仅保存在本地服务内存，刷新服务后失效。

默认 API 地址为 `https://api.deepseek.com`。自动联网调研使用 DeepSeek Responses API 的 `web_search`，因此会固定使用当前支持该能力的 `deepseek-v4-flash`；关闭“自动联网调研”后，才使用设置中的模型和 Chat Completions 接口。

## 工作流

1. 输入目标产品名称。目标、决策问题和受众可选；不填写时采用保守默认值。
2. 保持“自动联网调研”和“自动发现竞品”开启；已有竞品、URL 或内部数据也可以补充。
3. 系统搜索官网、定价、文档、更新日志和权威行业资料，自动补齐 3 个直接竞品和 1 个间接竞品/标杆。写完七层分析后，本地服务会打开各竞品官方网页版，实测同一条带来源研究任务；登录墙或仅下载仍标未跑。
4. 在竞争看板、深度分析、证据审计和建议路线图中校对结论。
5. 导出项目 JSON、PPTX 或 DOCX。文件由本地服务统一保存到 `报告下载/<调研主题><YYMMDD>/`，例如 `报告下载/办公平台agent260828/`，不再依赖浏览器的默认下载目录。

## 报告文件管理

- 专用根目录：`报告下载/`。
- 子目录优先使用“目标产品”作为调研主题，并自动追加导出当天的六位日期。
- 同一调研主题、同一天的 PPTX、DOCX 和 JSON 会归入同一文件夹；重新导出同一格式会更新对应文件。
- 导出完成后，网页会显示实际保存的完整路径。

Schema 1.2 新增用户画像与场景、Kano/HMW、产品五层、市场四类信号、三大数据系统、5W2H 埋点和可执行机会卡。评分与建议采用证据 ID 追溯：每个九维分数都有理由、证据引用和置信度；没有有效证据的高分或高信心建议会自动降到 5。证据审计页会显示来源覆盖、无效引用、未使用证据和自动降级记录。

## 安全

- HTML 和项目 JSON 不保存 API Key。
- 本地服务只监听 `127.0.0.1`。
- 开启联网调研时，本地服务会把任务发送给 DeepSeek，并由其搜索公开网页；请不要在输入中放入不应发送到外部服务的机密材料。
- 报告中的来源链接来自用户输入或联网调研结果，重要决策仍应人工复核原文。
- 请勿把 `.env.local`、日志或含密钥的终端截图提交到版本库。
