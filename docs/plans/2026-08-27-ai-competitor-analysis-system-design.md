# AI 产品竞品分析系统设计

## 目标

把 11 份产品课程蒸馏为一个可重复执行的 AI 产品竞品分析闭环：从需求和行业判断开始，经五层产品拆解、AI 专项评估、三大数据系统和商业效率分析，最终输出可决策、可追溯、可汇报的可视化结论。

## 方案选择

采用“HTML + 本地 Node 服务 + Codex 插件 Skill”的混合方案。纯静态网页虽然部署简单，但会把 API Key 暴露给浏览器且难以可靠生成带备注的 Office 文件；纯对话 Agent 又缺少可编辑看板。混合方案把交互、可视化与数据校对放在浏览器，把密钥、模型请求和 Office 文件生成留在仅监听 localhost 的服务端，并用插件 Skill 复用方法论。

## 分析架构

分析按七层展开：任务与用户需求、行业与周期、战略/范围/结构/框架/表现五层拆解、AI 能力与信任、用户/增长/营收数据系统、变现与商业效率、领导决策汇报。每个非平凡结论必须绑定证据、日期、来源和置信度；缺证据时标记为待验证，而不是补造事实。

评分采用九维 0-10 分模型，并允许按分析目标调整权重：市场匹配、产品体验、AI 能力、信任安全、增长、商业化、成本效率、生态与创新。总分用于定位，不替代证据和定性判断。

## 交付物

- HTML 看板：概览、定位矩阵、九维评分、商业效率、证据覆盖、建议路线图。
- PPTX：10 页决策叙事，原生可编辑图表，每页包含演讲备注与来源区块。
- DOCX：正式商业分析报告，含执行摘要、方法、对比表、单品拆解、指标系统、建议和证据登记。
- Codex 插件：识别竞品分析请求，指导调研、审计证据和生成结构化结果。

## 故障与验证

模型超时、空 JSON、截断和鉴权失败会返回可读错误，不覆盖当前项目。Office 导出先做输入规范化；测试检查 ZIP 内部结构、PPT 备注、Word 主文档和关键文本。最终用样例数据启动浏览器验证主要交互，并渲染检查 Office 输出。
